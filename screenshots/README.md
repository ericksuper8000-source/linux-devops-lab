# Screenshots

## Evidence Storage

- One folder per lab: `lab-00/`, `lab-01/`, …
- File names are descriptive: `01-os-release.png`, `02-users-list.png`, `03-running-services.png`.
- Prefer small, targeted captures (command + output) over full-screen shots.
- Command outputs that are not practical to screenshot may be saved as `.txt` files in
  the same folder.

> Evidence is part of the Definition of Done (see `AGENTS.md` and `docs/labs/README.md`).
> A lab without evidence is not finished.
